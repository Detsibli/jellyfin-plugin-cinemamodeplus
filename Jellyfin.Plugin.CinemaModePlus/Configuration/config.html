Cinema Mode Plus

Help

This plugin allows users to enable Jellyfin's Cinema Mode functionality to play intro content before movies. The plugin supports three types of intros: Trailer Pre-Rolls, Trailers, and Feature Pre-Rolls. Each of these can be configured/turned off in the sections below. All of this can be disabled at the user level by turning off Cinema Mode in the users Playback settings. For more information, access the user guide via the above help button. Pro-tip: Skip any pre-roll or trailer by pressing the next button in the player.

Cinema Mode Plus is based on Cinema Mode by CherryFloors (MIT License). It adds trailer libraries, combined trailer sources and Trailers4Jellyfin integration. Don't run it alongside the original Cinema Mode plugin, or intros will play twice.

Trailer Libraries

Pick libraries that contain only trailers. Don't pick your main Movies library: trailers inside movie folders are covered by the "Trailers in movie folders" source (use "Both"). Videos longer than 10 minutes are never used as trailers.
Also play trailers from the Trailers4Jellyfin plugin's download folder, so you don't need to select that library by hand. The folder must be part of a Jellyfin library.
Only applies when Enforce Rating Limit is on. Trailers for upcoming movies often have no rating yet, so Enforce Rating Limit would skip them. Turn this on to allow unrated videos from the trailer libraries.

This setting will cause any unrated content to have no trailers played prior and not be shown as a trailer. In this case unrated refers to any content where the "Parental Rating" meta data field is marked "Unrated" or left blank.
